# Botbito Discord Bot 🤖

TypeScript Discord bot built with `discord.js` and `googleapis`. It provides payout information from a Google Sheet and a private command guide.

Payout exports retain the organizer identity for each run, and `/set share status` skips Ready DMs for negative balances. Members can use `/set notification setting` to turn those DMs off per server; see [Commands](guides/commands.md), [Payouts and Sheets](guides/payouts.md), and [Signup Sheets](guides/signup-sheets.md) for details.
